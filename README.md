# Analogue-Ink-Wrapper
System tray application that interprets analogue input devices as a Windows Ink pen

All configuration options can be found inside the system tray by right clicking the program icon
ive verified the program works for myself and will not be actively providing support or maintenance
this program was mainly created to use the Swiftpoint Z3's analogue clicks as a pressure input for drawing in clip studio, but im sure it can be used anywhere you need pen pressure
it does not replicated other properties such as tilt


for best effect, assuming youre using it for drawing too, i reccommend separating your analogue input from your left click, since left click will give 100% signal
and personally i have my left mouse send F8 on click, feed the analogue signal, and release F8 on click release so the pen interpretation is only active when needed
then as said before, i bound left click to the fingertip button instead
